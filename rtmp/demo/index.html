rtmp.js —— RTMP 浏览器播放的本质 = WebSocket-FLV

浏览器没有 TCP API，无法直连 RTMP(1935)；可行链路是「RTMP 源 → 网关转封装 FLV → WebSocket 推送 → 本模块解析」。 延迟量级对照：HTTP-FLV ≈ 1~3s，WS-FLV ≈ 1~2s，WebRTC ≈ 0.2~1s。
前置：node samples/gateway/bin/gateway.js；本页经静态服务器打开（python3 -m http.server）。

连接参数

为什么不能直连？
浏览器出于安全沙箱不暴露 TCP 套接字 API，RTMP 握手（TCP 1935）在网页里发不出去。 请部署 ws-flv 网关（如本项目 samples/gateway、nginx-http-flv、SRS 等）， 用 ws-flv://网关地址/app/stream 播放；本页的「自动映射」也会把 rtmp://host/app/stream 改写为网关地址。
