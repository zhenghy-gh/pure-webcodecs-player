**验证层**：L1=node --test 单测｜L2=demo 浏览器手工/半自动｜L3=静态资源检查｜M=里程碑级核查。
**判定**：预期结果列即通过判据；"预期行为"类用例（如拒绝文案）不通过才算缺陷。
