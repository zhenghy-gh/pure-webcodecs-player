## 1. 设计原则

1. 零依赖纯 CSS + 一个轻量 ESM `skin.js`；不引入任何 UI 框架、图标库、字体文件。
2. 深色单主题（面向视频场景）；浅色仅预留 `[data-theme="light"]` 令牌覆盖位，本期不交付。
3. 变量即契约：页面自有样式只允许引用 `--pp-*` 变量，禁止硬编码色值（rgba 派生透明度除外）。
4. 全键盘可达：所有可交互控件必须有可见的 `:focus-visible` 焦点环；触控命中区 ≥ 44×44px。
5. 尊重 `prefers-reduced-motion`。
6. 双皮肤边界（至 captain M3 裁决前冻结）：遗留 `site.css(--dsk-*/.pui)` 与本皮肤 `--pp-*/.pp-*` 前缀隔离共存，互不扩展。

## 3. 控件态矩阵（含可达性硬性要求）

| 态 | 视觉 |
|---|---|
| hover | 底色 `--pp-hover`；accent 文字变 `--pp-accent-hover` |
| active | 底色 `--pp-active-bg`；accent 实心变 `--pp-accent-active` |
| disabled | `opacity:.4; cursor:not-allowed`，不响应 hover/active |
| **focus-visible** | `outline: 2px solid var(--pp-accent); outline-offset: 2px;` 保持控件圆角。**禁止移除 outline 不给替代**；鼠标点击不触发、Tab 导航必触发（用 `:focus-visible` 不用 `:focus`） |
| 错误 | 描边换 `--pp-danger` + 同色提示行 |

补充：滑杆必须是原生 `input[type=range]` 定制（保留键盘与 ARIA slider 语义），拖动中加 `.is-scrubbing` 放大 thumb 关过渡；toast 容器 `aria-live="polite"`、错误类 `role="alert"`；装饰性图标 `aria-hidden="true"`，纯图标钮必须有中文 `aria-label`；`prefers-reduced-motion: reduce` 下关闭全部动画（spinner 退化为透明度呼吸）。

## 4. BEM 类名约定

前缀 `.pp-`；块小写连字符、元素 `__`、修饰符 `--`、瞬时态 `.is-*`；JS 行为钩子用 `data-pp-*` 属性。最小集：

`.pp-btn(--solid/--ghost/--icon/--danger)` · `.pp-range(--progress/--volume)` · `.pp-progress(__fill/__buffer)` · `.pp-panel/__title` + `.pp-kv(__key/__val--ok/warn/bad)` + `.pp-tag(--accent)` + `.pp-badge(--ok/--warn/--danger/--live)` · `.pp-drop(__icon/__hint, .is-over)` · `.pp-stage(__viewport/__overlay, .has-error/.is-buffering)` · `.pp-topbar(__brand/__nav/__actions)` + `.pp-tabs__item.is-active` · `.pp-toast(--info/--ok/--warn/--danger, __close)` · `.pp-field(__input/__btn/__help, .is-invalid)` · `.pp-card` · `.pp-spinner(--sm)` · `.pp-kbd` · `.pp-divider` · 布局工具 `.pp-row/.pp-col/.pp-grow/.pp-page/.pp-main/.pp-aside`


### 6.2 分区清单与导航模型

顶部导航（全局，sticky）＝品牌记号 + PurePlay 字标 + 模块 tabs + 右侧 actions；tabs 即模块切换，激活态由 skin.js 按 pathname 自动高亮（`[data-pp-tabs]`）。所有 demo 页相互独立、可静态直开，不存在跨页依赖状态。

### 6.3 标准网格（页型 B）

```
┌────────────────────────────────────────┐
│ topbar  PurePlay · [模块 tabs] [actions] │ 52px sticky
├───────────────────────────┬────────────┤
│  stage（画布区 16:9）        │ info-panel │
│  L0画面/L1字幕/L2状态/L3错误  │ 320px      │
├───────────────────────────┤ 独立滚动     │
│  controls（控制条 56px）     │            │
└───────────────────────────┴────────────┘
```

CSS：`.pp-page` 两列网格 `minmax(0,1fr) + var(--pp-panel-w)`，内容限宽 1440px 居中。断点：≤1120px 面板 280px；≤1024px 单列、面板移到主列下方；≤640px 控制区紧凑化＋触控命中 44px。

### 6.4 信息面板标准块序（所有模块统一）

① 媒体信息（kv：容器/时长/分辨率/帧率/码率，编码用 tag）② 轨道列表（类型图标+名称语言+编码 tag+选中态）③ 实时统计（mono kv，≥500ms 刷新；丢帧>1% 转警告色）④ **模块特化块**（字幕＝样式表＋未支持标签清单；桥接＝网关诊断）⑤ 事件日志（可选折叠，最近 N 条）。

### 6.5 三态设计语言

空态＝dropzone 虚线卡（图标+文案+地址输入+示例按钮）；加载＝stage 中央 spinner＋中文文案；错误＝三级体系（badge 面板态 / toast 非阻塞 / errbox 阻断卡，错误码 `E_<域>_<名>`，映射见附录 A）。直播态左上角红点呼吸徽章。

## 7. 字幕呈现层级与样式映射规范（ASS/SRT 在皮肤中的表现）

> 本节同时是 CONTRACTS §8「Cue 流」在展示层的落地处，及 captain《初验-DESIGN》整改项②的交付。

### 7.1 stage 内层级栈（自下而上，z-index 就近取整）

| 层 | 内容 | z-index | 说明 |
|---|---|---|---|
| L0 媒体画面 | `<video>`/canvas | 0 | letterbox 用 `--pp-bg-deep` |
| **L1 字幕覆盖层** | 专用字幕 canvas | 10 | `pointer-events:none`，永不拦截交互；独立于媒体 canvas，避免清屏互踩 |
| L2 舞台状态层 | buffering spinner / live 徽章 / dropzone | 20 | 半透明，不遮字幕关键区 |
| L3 错误盒 errbox | 阻断错误卡 | 30 | 出错时字幕暂停刷新 |
| L4 全屏悬浮控制条 | 全屏时的 controls | 40 | 底部渐变遮罩，3s 无操作隐藏 |

toast 是**全局层**（`--pp-z-toast:300`，挂 body），永远高于舞台内一切层；errbox 与 toast 的分工：阻断性错误走 errbox（不自动关），过程性警告走 toast（自动关）。

### 7.2 SRT/VTT 缺省渲染样式（无样式信息的格式，由皮肤提供 Default Style）

| 参数 | 规定 | 备注 |
|---|---|---|
| 字体 | `var(--pp-font)` 同栈系统黑体 | 不引 webfont |
| 字号 | 画布高 × 5.5%（PlayRes 兜底 640×360 时约 42） | 随容器缩放 |
| 填充 | `#FFFFFF` 不透明 | **刻意不用 `--pp-text`**：画面可读性优先于主题一致性 |
| 描边 | `#000000`，宽 = 字号 ÷ 21（42px 字号≈2px），round 连接 | 对比兜底 |
| 阴影 | offset 2px `rgba(0,0,0,.85)` | BorderStyle=1 形态 |
| 底衬形态 | BorderStyle=3 时整行底框 `rgba(0,0,0,.6)` | ASS 可显式指定 |
| 锚点 | 底部居中（an=2），底边距 = 画布高 × 5%，且不低于控制条高度 | 安全边距 |
| 行高/堆叠 | 1.25；多 cue 自下而上堆叠 gap=4 逻辑单位 | 简化碰撞模型 |

**对比度铁律**：白字＋黑描边保证任意画面 ≥4.5:1；禁止无描边且无底衬的字幕直压亮画面。

### 7.3 ASS 样式规则

源文件 Style 表**优先于** §7.2 缺省（颜色 &HAABBGGRR 小端解析、九宫 \an、\pos/\move/\org/\fad/\fscx/\fscy/\frz/矩形 \clip 按白名单生效）；行内标签逐段快照样式。白名单外标签（`\t \k \p \bord \be…`）忽略并计入信息面板「未支持标签清单」，绝不崩溃。

### 7.4 降级阶梯（缺 libass-wasm 时）

1. 默认：本仓 JS 排版求解器＋Canvas 2D 渲染（零依赖，白名单效果）。
2. 特效超白名单：受支持部分照常渲染，未支持标签静默忽略＋清单展示。
3. 极端降级（Canvas 不可用）：DOM 文本叠层白字黑边纯文本，仍保时间同步。
任何一级都不得抛未捕获异常；libass-wasm 属可选增强（README 声明），加载失败自动回落第 1 档。

### 7.5 时间同步

渲染时钟以播放器音频主时钟为准（整数 µs）；demo 无音轨时用性能软时钟。Cue 命中区间的语义：`startUs ≤ t < endUs`。

## 8. qa 抽查清单（M3 视觉走查口径）

1. 除 skin.css 外无裸十六进制色值；2. Tab 遍历全控件有可见焦点环；3. reduced-motion 无动画；4. 四断点（1440/1120/1024/640）无横向滚动无遮挡；5. 五态（idle/buffering/playing/live/error）控制条表现符合规范；6. 字幕层不挡点击、白字黑边、底部安全边距不被控制条侵入；7. Network 无第三方请求。
